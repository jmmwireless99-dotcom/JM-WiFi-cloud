SOSCIAL Park CCTV

Isang APK para sa Android phone at Android TV / TV box.

Version 1.2.0 — update (D1–D5 live cameras)

⬇ Download APK (phone + TV) ⬇ Download TV APK (same build) ⬇ Download ZIP

Android phone

  1. Buksan ang link sa Chrome (huwag Messenger/FB)
  2. Tap Download → buksan ang file → Install
  3. Payagan ang Unknown apps kung tanungin
  4. Open app → login: admin

Android TV / TV box

  1. I-download ang APK sa phone, USB stick, o Downloader app (code/URL)
  2. I-install sa TV (Unknown sources / Install unknown apps)
  3. Hanapin ang SOSCIAL Park CCTV sa Apps row
  4. Remote (D-pad) → login → piliin ang camera

Kung nasa Messenger ka ngayon: i-tap ang ⋮ → Open in Chrome / Browser, tapos download ulit.
