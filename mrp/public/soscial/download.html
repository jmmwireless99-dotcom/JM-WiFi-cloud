Android phone

  1. Buksan ang link sa Chrome (huwag Messenger/FB)
  2. Tap Download → buksan ang file → Install
  3. Payagan ang Unknown apps kung tanungin
  4. Open app → ilagay ang viewer key (mula sa admin)
  5. O sa Chrome: /social → Install App (home screen)

Android TV / TV box

  1. I-download ang APK sa phone, USB stick, o Downloader app (code/URL)
  2. I-install sa TV (Unknown sources / Install unknown apps)
  3. Hanapin ang SOCIAL Park CCTV sa Apps row
  4. Ilagay ang viewer key → piliin ang camera

Kung nasa Messenger ka ngayon: i-tap ang ⋮ → Open in Chrome / Browser, tapos download ulit. Kapag i-share ang link, lalabas ang JM Wireless / SOCIAL PARK logo.
